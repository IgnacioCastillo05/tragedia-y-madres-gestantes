# Tragedia y Madres Gestantes

Bibliografía de investigación sobre el impacto de tragedias, desastres y emergencias sanitarias en madres gestantes y lactantes.

Sitio publicado (GitHub Pages): **https://ignaciocastillo05.github.io/tragedia-y-madres-gestantes/**

## Contenido

- [`docs/`](docs/index.md) — seis ejes temáticos (lactancia en emergencias, contención emocional, acompañamiento infantil, validación emocional, incertidumbre del futuro, culpa materna).
- [`casos/`](casos/index.md) — casos por país y tipo de desastre (México, Estados Unidos, Haití, Ecuador/Perú, Turquía-Siria, Japón, Italia, y revisiones multipaís).

Todos los ítems son artículos reales publicados en revistas indexadas (no tesis ni TFG/TFM), verificables en Google Académico, SciELO, Dialnet, PubMed/PMC o el sitio de la revista.

## Estructura del repo

Este repositorio usa Jekyll (el mismo generador que GitHub Pages ejecuta automáticamente):

```
_config.yml        configuración del sitio
_layouts/           plantilla base (sidebar, breadcrumb, tipografía)
wiki.css            estilos del sitio
index.md            página de inicio
docs/                ejes temáticos
casos/               casos por país
```

Para habilitar la publicación: **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`**.
